# サッカークラブ経営ゲーム

PCのブラウザで遊ぶ、リアル志向のサッカークラブ経営シミュレーション。
今は **フェーズ0（試合エンジンの試作）** で、画面はなく、ターミナルで試合を動かす。

## 必要なもの

- Node.js 22 以上

## 使い方

最初に一度だけ、必要な道具を入れる。

```sh
npm install
```

### 1試合を動かす

```sh
npm run match
```

実況、スコア、スタッツ、選手ごとの評価点が表示される。

| オプション | 意味 |
| --- | --- |
| `--seed=42` | 試合のシード（乱数の元）。同じシードなら同じ試合になる |
| `--all` | 細かい実況（パス、ドリブル、タックルなど）もすべて表示する |
| `--home-pressing=2` | ホームのプレスの強さ（-2〜2） |
| `--away-mentality=-1` | アウェイの攻撃と守備のバランス（-2〜2） |

チーム指示は `mentality`（攻撃と守備のバランス）、`defensive-line`（守備ラインの高さ）、`pressing`（プレスの強さ）、`width`（攻撃の幅）、`passing-length`（パスの長さ）、`tempo`（攻めのテンポ）の6つ。`--home-` か `--away-` を前に付けて指定する。

```sh
npm run match -- --seed=42 --home-pressing=2 --away-defensive-line=-1
```

### たくさん試合を回して、結果の分布を確かめる

```sh
npm run simulate            # 約1分半
npm run simulate -- --n=300 # 試合数を減らして早く終わらせる
```

平均ゴール数、ホームの勝率、引き分けの割合、計算時間を、要件定義書の目標と比べて OK / NG を表示する。
力の差がある試合と、プレスの強さを変えた場合の比較も出す。

### 自動テスト

```sh
npm test           # 約30秒
npm run typecheck  # 型のチェック
```

## フォルダの構成

| 場所 | 中身 |
| --- | --- |
| `src/engine/types.ts` | 選手、チーム、試合結果などのデータの形 |
| `src/engine/match.ts` | 試合エンジン本体（ゾーン方式） |
| `src/engine/formations.ts` | フォーメーションと、攻撃時・守備時の立ち位置 |
| `src/engine/config.ts` | 試合エンジンの調整用の数値 |
| `src/engine/commentary.ts` | 実況の文章 |
| `src/engine/summary.ts` | たくさんの試合結果の集計 |
| `src/engine/rng.ts` | シード付きの乱数 |
| `src/data/` | 選手とチームの自動生成、名前の材料 |
| `src/cli/` | ターミナルで動かすためのコマンド |
| `test/` | 自動テスト |

## 試合エンジンのしくみ（要点）

- ピッチを縦6×横5の30マスに分け、ボールを持った選手のプレー（パス、ドリブル、シュート、クロス、クリア）を一手ずつ計算する
- 各選手は、フォーメーションとチーム指示から「攻撃時の位置」と「守備時の位置」を持ち、近くのマスに影響を与える
- プレーの成功率は、攻める側の能力と、そのマスで守る側がかけている「圧力」で決まる
- プレスは「相手陣内でボールに寄せる力」として圧力に加わる。前線と中盤の運動量・スピードが高いほど強い
- スタミナは時間とともに減り、能力値が下がる。プレスやテンポを上げると早く減る
- 試合の計算では、能力値の平均（12）からの差を0.85倍に縮めて使い、番狂わせが起きる余地を残している

結果の分布を変えたいときは、まず `src/engine/config.ts` の数値を変えて、`npm run simulate` で確かめる。
